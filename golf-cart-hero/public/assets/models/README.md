# Cart GLB models

Custom **open-top** 3D golf cart meshes used in gameplay:

| File | Cart |
|------|------|
| `carts/yamaha.glb` | White Yamaha Drive2-style |
| `carts/evolution.glb` | Long cyan Evolution electric |
| `carts/hotrod.glb` | Blue/silver street rod |

## How they’re made

There is no Blender install required on this machine. Models are generated by:

```bash
npm.cmd run export-carts
```

That runs `scripts/export-cart-glbs.mjs` (Three.js + GLTFExporter) and writes the three `.glb` files here.

## Design rules

- **Open-top** (windshield only) so Florida critter drivers stay visible
- Real multi-mesh 3D (turn with the racer — not photo stickers)
- Loaded at startup via `src/game/assets/cartGlb.ts`; procedural fallback if a file is missing

## Improving further (optional)

If you install Blender later, you can replace these GLBs with hand-sculpted models (same filenames, similar scale: ~1.5–2.2 units wide, wheels near y≈0.4). Keep the canopy off so drivers remain readable from the chase cam.
